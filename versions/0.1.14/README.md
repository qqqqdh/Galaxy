# Galaxy IDE 0.1.14

- 상단 **AI** 메뉴에서 Codex, Claude Code, AGY를 고르면 같은 프로젝트의 코드와 대화를 한 화면에 표시합니다. 화면 폭에 따라 좌우 또는 위아래로 배치합니다.
- 편집기나 AI 창을 터치하거나 `Ctrl+T`로 입력 위치를 바꿉니다. **숨기기**를 누른 뒤에도 **AI → 대화 보기**에서 같은 세션을 이어갑니다.
- AI 창에서 편집기로 이동하거나 AI가 종료되면, 외부에서 수정된 파일 중 미저장 편집이 없는 문서를 다시 읽습니다.

설치 파일은 Ubuntu ARM64용 `galaxy-ide-linux-arm64`입니다. [설치 및 사용법](../../cli-ide/README.md)

Go 테스트로 좌우·위아래 배치와 포커스 전환을 확인했습니다. Galaxy Tab S8+에서 실제 Codex와 코드 편집기를 동시에 띄우고, 편집 중 및 AI 창 숨김·복원 후에 같은 Codex 초안이 유지되는 모습을 확인했습니다.
