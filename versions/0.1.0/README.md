# Galaxy IDE 0.1.0

Ubuntu ARM64에서 실행하는 터미널 IDE의 첫 버전입니다. 파일 탐색기, 여러 문서 편집, 저장, 검색 및 프로젝트 명령 실행을 제공합니다.

[ARM64 Linux 실행 파일과 라이선스](https://github.com/qqqqdh/Galaxy/releases/tag/ide-v0.1.0)

실행 파일의 SHA-256은 `7b3dbdababa42665dfaff1a13471f7188fb00c2ae4e8633b3747619502c4e2e9`입니다.

이 버전의 태그에는 배포 기록을 보관합니다. 당시 배포한 실행 파일은 릴리스 첨부 파일에서 받을 수 있습니다.
