# Galaxy IDE 0.1.21

- 코드 자동완성 후보를 마우스로 클릭하거나 터치해 적용할 수 있습니다.
- Claude 로그인 URL이 AI 창의 오른쪽 끝에서 끝날 때 다음 줄 안내 문구가 주소에 섞이는 문제를 수정했습니다.
- AI를 전환할 때 이전 프로세스를 종료하고, 프로그램이 입력을 읽지 않을 때도 긴 붙여넣기가 IDE 화면을 멈추지 않도록 했습니다.
- 편집기와 터미널 창의 경계에서 한글 문자와 탭 강조가 옆 영역을 침범하는 문제를 수정했습니다.

갤럭시 탭의 Ubuntu용 `galaxy-ide-linux-arm64`를 제공합니다.

[설치 및 사용법](https://github.com/qqqqdh/Galaxy/tree/ide-v0.1.21/cli-ide)
