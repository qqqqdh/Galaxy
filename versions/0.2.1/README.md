# Galaxy IDE 0.2.1

- AI와 프로젝트 셸의 출력을 세션별 고루틴에서 순서대로 해석하고, 완성한 화면을 IDE에 전달합니다.
- 일반 글자를 입력할 때 편집기, 탭, 상태 표시와 필요한 오류 표시만 다시 그립니다.
- 전체 폭의 터미널 스크롤은 줄 버퍼를 재사용합니다. 이전 출력 기록은 최대 1만 줄을 순서대로 유지합니다.

갤럭시 탭의 Ubuntu용 `galaxy-ide-linux-arm64`를 제공합니다.

[설치 및 사용법](https://github.com/qqqqdh/Galaxy/tree/ide-v0.2.1/cli-ide)
