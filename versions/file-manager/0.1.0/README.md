# Galaxy 파일 관리자 0.1.0

- 터치와 키보드로 폴더 탐색, 복사·이동·삭제, 이름 변경과 폴더 생성을 지원합니다.
- ZIP, TAR.GZ, TGZ를 별도 폴더에 풀고 기존 파일을 보호합니다.
- 파일 전송을 지원하는 Galaxy Terminal에서는 Android 공유 폴더를 열 수 있습니다.

갤럭시 탭의 Ubuntu용 `galaxy-files-linux-arm64`와 Linux x86-64용 `galaxy-files-linux-amd64`를 제공합니다. Linux 터미널에서 폴더 이동, 파일 복사, ZIP 압축 해제를 확인했습니다.

[설치와 사용법](https://github.com/qqqqdh/Galaxy/tree/file-manager-v0.1.0/file-manager)
