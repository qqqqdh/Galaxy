# Galaxy 파일 관리자 0.1.2

- **휴지통으로 이동**은 파일을 보관합니다. **휴지통**에서 원래 위치에 복원하거나 영구 삭제할 수 있습니다.
- 프로젝트 백업은 숨김 파일과 폴더 안에 있는 Git 기록을 포함합니다. Galaxy Terminal 0.4.16에서 **Android에 백업**으로 저장 위치를 선택할 수 있습니다.
- 백업 파일을 **압축 풀기**로 열면 새 폴더에 복원합니다.

갤럭시 탭의 Ubuntu용 `galaxy-files-linux-arm64`와 Linux x86-64용 `galaxy-files-linux-amd64`를 제공합니다.

[설치 및 사용법](https://github.com/qqqqdh/Galaxy/tree/file-manager-v0.1.2/file-manager)
