# Galaxy 파일 관리자 0.1.1

- GitHub가 제공하거나 `git archive`로 만든 TAR.GZ에서 PAX 전역 헤더를 건너뛰고 파일을 풉니다.
- 압축을 푼 폴더에는 일반 폴더와 같은 권한을 적용합니다.

갤럭시 탭의 Ubuntu용 `galaxy-files-linux-arm64`와 Linux x86-64용 `galaxy-files-linux-amd64`를 제공합니다.

[설치와 사용법](https://github.com/qqqqdh/Galaxy/tree/file-manager-v0.1.1/file-manager)
