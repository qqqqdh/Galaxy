# Galaxy Terminal 0.4.9

Galaxy Terminal의 첫 GitHub 배포입니다. 이 버전에는 앱 목록과 홈 화면에 표시되는 Galaxy Terminal 아이콘이 적용됐습니다.

- 물리 키보드로 한글을 조합하며 입력하고, 트랙패드로 스크롤·선택·복사할 수 있습니다.
- 앱 안에서 Ubuntu 24.04 LTS를 설치하고 일반 사용자 계정과 `sudo`를 사용합니다.
- Ubuntu 로그인 세션은 `who`와 `w`에 표시됩니다. 내장 브라우저에서 웹이나 로컬 개발 서버를 열 수 있습니다.

[Android 설치 파일](https://github.com/qqqqdh/Galaxy/releases/tag/terminal-v0.4.9) · [사용법과 Windows 빌드](../../../terminal/README.md)

패키지 이름은 `dev.galaxy.terminal`, Android 버전 코드는 `15`입니다. 기본 셸은 Android 8 이상, Ubuntu는 ARM64 Android 9 이상에서 사용합니다.
