# Galaxy Terminal 0.5.0

- 가려진 셸은 실행과 출력 처리를 계속합니다. 화면 그리기와 크기 계산은 탭을 다시 열 때 재개합니다.
- 셸 탭의 버튼을 재사용하고, 연속 출력은 묶어서 터미널 화면에 전달합니다.
- 두 손가락 스크롤 감도를 높였습니다.
- 일반 셸의 한글 글자 삭제와 Android 키보드에서 한글 입력 직후 Enter 동작을 개선했습니다.

정식 설치 파일은 `Galaxy-Terminal.apk`입니다. Android 패키지 이름은 `dev.galaxy.terminal`, 버전 코드는 `23`입니다. Galaxy IDE는 Ubuntu에 별도로 설치하는 실행 파일입니다.
