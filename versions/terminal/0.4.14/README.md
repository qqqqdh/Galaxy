# Galaxy Terminal 0.4.14

Galaxy IDE 0.1.19 이상에서 Claude Code 요청을 입력할 때, `ㅎ → 하 → 한`처럼 조합 과정이 실제 입력줄에 즉시 반영됩니다. 글자를 확정할 때 이미 입력된 글자를 다시 보내지 않습니다.

패키지 이름은 `dev.galaxy.terminal`, 버전 코드는 `20`입니다. 설치 파일은 `Galaxy-Terminal.apk`입니다.

Galaxy Tab S8+의 실제 Claude Code 입력창에서 삼성 키보드로 `ㅎ → 하 → 한`을 입력해 공백을 누르기 전 각 단계가 반영되고, 확정 후 `한` 하나만 남는 것을 확인했습니다. 공백 없이 한영을 바꾸며 `한abc글`도 입력했습니다.
