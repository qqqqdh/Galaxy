# Galaxy Terminal 0.4.16

- Ubuntu에서 여러 셸을 열고 이름을 붙여 전환할 수 있습니다.
- 브라우저를 다시 열면 열려 있던 페이지, 방문 기록, 스크롤이 유지됩니다. 넓은 가로 화면에서 터미널과 미리보기를 나란히 볼 수 있습니다.
- Ubuntu에서 `galaxy-open .`으로 Galaxy 파일 관리자를 열고, `galaxy-share 파일`로 Android 공유 메뉴를 열 수 있습니다. `galaxy-doctor .`는 개발 도구와 Go 프로젝트의 언어 서버를 점검합니다.

정식 설치 파일은 `Galaxy-Terminal.apk`입니다. Android 패키지 이름은 `dev.galaxy.terminal`, 버전 코드는 `22`입니다.

[설치 및 사용법](https://github.com/qqqqdh/Galaxy/tree/terminal-v0.4.16/terminal)
