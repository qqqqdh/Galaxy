# Galaxy Terminal 0.4.12

- Claude Code 인증 링크를 누르면 Android 브라우저에서 로그인합니다. Google 로그인이 내장 브라우저의 중간 화면에 멈추던 문제를 해결합니다.
- 일반 웹 링크는 내장 브라우저에서 엽니다.

패키지 이름은 `dev.galaxy.terminal`, 버전 코드는 `18`입니다. 설치 파일은 `Galaxy-Terminal.apk`입니다.

Galaxy Tab S8+의 Ubuntu 터미널에서 `claude auth login`으로 생성한 전체 링크를 눌러 Firefox에서 Claude 인증 반환 주소까지 도달했습니다. 좁은 IDE AI 창에서 여러 줄로 나뉜 링크는 별도의 Galaxy IDE 0.1.17 변경으로 처리합니다. 주소 분류 및 터미널 테스트를 통과했습니다.
