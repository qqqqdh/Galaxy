# Galaxy Terminal 0.4.15

- `cat`처럼 실행 중인 프로그램에서도 조합 중인 한글이 입력 줄에 표시되고 커서가 글자 뒤를 따라갑니다.
- 화면 방향키를 누르면 조합한 한글을 확정한 뒤 방향키를 전달합니다.
- Ubuntu의 **⋯ → Android 파일 전송**에서 Android로 파일을 보내거나 가져올 수 있습니다. Ubuntu의 전송 폴더는 `/mnt/galaxy-transfer`입니다.

정식 설치 파일은 `Galaxy-Terminal.apk`입니다. Android 패키지 이름은 `dev.galaxy.terminal`, 버전 코드는 `21`입니다.

[설치 및 사용법](https://github.com/qqqqdh/Galaxy/tree/terminal-v0.4.15/terminal)
