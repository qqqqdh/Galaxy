# Galaxy Terminal 0.4.11

- Codex 화면을 터치하거나 클릭해도 Android 입력기가 네이티브 입력창에 연결된 상태를 유지합니다. WebView 입력창으로 전환되면서 발생하던 중복과 한글 자모 분리를 수정했습니다.
- 삼성 입력기가 조합 상태로 유지하는 영문도 입력하거나 지우는 즉시 터미널에 반영합니다. Codex의 빠른 입력 묶기도 해제합니다.

패키지 이름은 `dev.galaxy.terminal`, 버전 코드는 `17`입니다. 로컬 설치 파일은 `dist/Galaxy-Terminal.apk`입니다.

Galaxy Tab S8+에 설치한 뒤 실제 Codex CLI 입력창에 탭하고 `한abc글`을 공백과 함께 24회, 중간 공백 없이 20회 입력했습니다. 88회의 한영 전환에서 중복과 자모 분리가 없었고, 영문 입력과 Backspace가 스페이스 입력 전에 반영됐습니다. 키 이벤트는 ADB로 전달했습니다.
