# Galaxy IDE 0.1.11

Java, JavaScript, HTML, CSS, Go, Python, Rust 언어 서버를 지원합니다. 편집 중인 내용으로 자동완성을 요청하고, 서버가 제공하는 정의 위치와 진단을 편집기에서 확인할 수 있습니다. Ctrl+R로 Java·JavaScript·Go·Python·Rust 파일을 실행합니다. HTML·CSS에서는 기기 안에서만 열리는 미리보기 서버를 시작합니다.

Windows에서 일곱 실제 언어 서버의 자동완성, Python의 정의 이동과 미저장 문서 오류 위치를 확인했습니다. [Ubuntu 설치 방법과 언어별 도구](../../cli-ide/README.md#언어별-실행과-코드-지원)를 참고하세요.
