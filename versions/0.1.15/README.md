# Galaxy IDE 0.1.15

- 가로 화면에서 파일 탐색기, 코드 편집기, AI 창을 나란히 표시합니다. 폭이 좁으면 코드 아래에 AI 창을 둡니다.
- 상단 **탐색기** 버튼으로 파일 목록을 접거나 다시 펼칩니다. 파일 이름이 칸을 넘으면 항목에 포커스를 두고 아래 상태 줄에서 전체 경로를 확인할 수 있습니다.

설치 파일은 Ubuntu ARM64용 `galaxy-ide-linux-arm64`입니다. [설치 및 사용법](../../cli-ide/README.md)

Go 테스트와 ARM64 빌드를 통과했습니다. Galaxy Tab S8+에서 파일 목록으로 `index.html`과 `README.md`를 전환하고, 탐색기를 접었다가 펼쳐도 오른쪽 Codex 입력이 유지되는 것을 확인했습니다.
