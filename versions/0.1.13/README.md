# Galaxy IDE 0.1.13

- 자동완성 목록을 커서 아래에 띄우고 공간이 부족하면 위에 표시합니다. 위·아래 방향키로 고르고 Tab으로 적용하거나 후보를 클릭합니다. 타이핑 후 언어 서버에 요청하기까지의 대기 시간을 350ms에서 175ms로 줄였습니다.
- 상단 **AI** 메뉴에서 Codex, Claude Code, AGY를 전체 화면으로 실행합니다. 도구를 종료하고 Enter를 누르면 편집기로 돌아갑니다.
- 하단의 **터미널 확대** 또는 F8로 실행 중인 프로젝트 터미널을 전체 화면으로 전환합니다. **편집기로** 또는 Ctrl+T로 돌아가도 같은 셸과 프로세스가 유지됩니다.

설치 파일은 Ubuntu ARM64용 `galaxy-ide-linux-arm64`입니다. [설치 및 사용법](../../cli-ide/README.md)

Go 테스트와 ARM64 빌드를 통과했습니다. Galaxy Tab S8+에서 clangd 후보 표시와 Tab 삽입, 같은 프로젝트 셸의 7행에서 28행으로 확대 및 편집기 복귀, AI 메뉴의 Codex 전체 화면 시작을 확인했습니다.
