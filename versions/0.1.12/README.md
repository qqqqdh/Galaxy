# Galaxy IDE 0.1.12

HTML·CSS 미리보기 서버와 IDE가 같은 터미널에서 Ctrl+C를 함께 받아 편집기가 종료되던 문제를 수정했습니다. Ctrl+C로 작업을 중단하고 Enter를 누르면 열린 문서로 돌아옵니다.

Galaxy Tab S8+의 Ubuntu ARM64에서 Java, JavaScript, HTML, CSS, Go, Python, Rust 자동완성 검사를 통과했습니다. Python에서 미저장 코드의 진단과 정의 이동을 확인했고, HTML과 CSS는 Galaxy Terminal 내장 브라우저로 미리보기를 확인했습니다.
