# Galaxy IDE 0.2.0

- 상단 **명령** 또는 F10으로 실행 명령을 검색하고 실행할 수 있습니다.
- 편집기에 줄 번호를 표시하고, Alt+↑와 Alt+↓로 오류 위치를 이동할 수 있습니다.
- 언어 서버가 찾은 참조를 열고, 프로젝트의 심볼 이름 변경을 미리 본 뒤 편집 탭에 적용할 수 있습니다.
- 커서가 있는 Go 테스트를 실행하고 실패 결과에서 코드 위치를 열 수 있습니다.
- 웹 미리보기를 열어 둔 상태에서 파일을 저장하면 브라우저가 자동 갱신됩니다.
- 같은 문서의 CSS 색상 변수를 미리 보고, 색상 네모를 눌러 색상과 불투명도를 바꿀 수 있습니다.
- 같은 프로젝트를 다시 열면 저장된 탭, 커서와 스크롤 위치를 복원합니다.

갤럭시 탭의 Ubuntu용 `galaxy-ide-linux-arm64`를 제공합니다.

[설치 및 사용법](https://github.com/qqqqdh/Galaxy/tree/ide-v0.2.0/cli-ide)
