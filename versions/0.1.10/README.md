# Galaxy IDE 0.1.10

clangd로 C/C++ 코드 완성 후보를 표시하고 선택한 이름을 삽입합니다. 함수 정의가 다른 파일에 있으면 그 파일과 줄로 이동합니다. 열린 문서의 미저장 내용을 언어 서버에 전달합니다.

[ARM64 Linux 실행 파일과 라이선스](https://github.com/qqqqdh/Galaxy/releases/tag/ide-v0.1.10)

실행 파일의 SHA-256은 `6316ef7f19d5356cb93110358f52b2037055b451fbc3a756f5f0d025043efebb`입니다.

갤럭시 탭 S8+의 Ubuntu ARM64와 clangd 18.1.3에서 C와 C++ 두 파일 통합 검사를 통과했습니다. 자동완성은 Ctrl+K, 정의 이동은 Ctrl+] 또는 F12로 직접 실행할 수 있습니다.
