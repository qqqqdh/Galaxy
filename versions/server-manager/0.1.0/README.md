# Galaxy 서버 실행 관리자 0.1.0

- 프로젝트별 서버 명령, 작업 폴더와 브라우저 주소를 저장합니다.
- 서버를 시작하거나 중지하고 최근 표준 출력과 오류를 확인할 수 있습니다.
- 관리자 화면을 다시 열어 같은 Ubuntu 세션에서 돌고 있는 서버를 관리할 수 있습니다.

갤럭시 탭의 Ubuntu용 `galaxy-servers-linux-arm64`와 Linux x86-64용 `galaxy-servers-linux-amd64`를 제공합니다. Linux 터미널에서 서버 등록·시작, HTTP 응답, 로그 표시, 관리자 재접속과 중지를 확인했습니다.

[설치와 사용법](https://github.com/qqqqdh/Galaxy/tree/server-manager-v0.1.0/server-manager)
