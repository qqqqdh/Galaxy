# Galaxy 서버 실행 관리자 0.1.1

- 등록한 서버의 프로세스 상태와 TCP 포트의 연결 가능 여부를 따로 표시합니다.
- 최근 로그에 포트 충돌 메시지가 있으면 포트 상태 옆에 표시합니다.
- 동시 출력 로그의 기록과 순환을 직렬화합니다.

갤럭시 탭의 Ubuntu용 `galaxy-servers-linux-arm64`와 Linux x86-64용 `galaxy-servers-linux-amd64`를 제공합니다.

[설치 및 사용법](https://github.com/qqqqdh/Galaxy/tree/server-manager-v0.1.1/server-manager)
