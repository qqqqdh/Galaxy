# Galaxy IDE 0.1.16

- 편집기 아래 `◀`·`▶` 버튼으로 긴 코드 줄을 가로로 이동합니다. 바 가운데에는 현재 화면에 보이는 첫 열이 표시됩니다.
- 편집기에 포커스를 두고 `Alt+←` 또는 `Alt+→`를 눌러도 이동할 수 있습니다. 포인터를 편집기에 두고 `Shift`와 스크롤을 함께 사용하거나 마우스로 바를 드래그할 수도 있습니다.
- 가로 이동 중에도 커서, 선택 영역, 세로 위치를 유지합니다.

설치 파일은 Ubuntu ARM64용 `galaxy-ide-linux-arm64`입니다. [설치 및 사용법](../../cli-ide/README.md)

Go 테스트와 ARM64 빌드를 통과했습니다. Galaxy Tab S8+에서 파일 탐색기와 실제 Codex 창을 함께 띄우고, `index.html`의 긴 줄을 터치 버튼과 `Alt+→`로 이동한 뒤 첫 열로 돌아오는 것을 확인했습니다.
