# Galaxy IDE 버전 이력

| 버전 | 추가하거나 개선한 내용 |
|---|---|
| 0.1.15 | AI 창을 열어도 파일 탐색기를 함께 표시합니다. 상단 탐색기 버튼으로 파일 목록을 접거나 펼칩니다. |
| 0.1.14 | 코드와 AI를 같은 화면에서 보고 입력 위치를 전환합니다. AI 창을 숨겼다가 같은 대화로 돌아올 수 있습니다. |
| 0.1.13 | 자동완성 후보를 커서 옆에서 더 빨리 표시합니다. AI 전용 실행 메뉴와 프로젝트 터미널 전체 화면 전환을 추가했습니다. |
| 0.1.12 | Ctrl+C로 웹 미리보기나 실행 중인 작업을 중단한 뒤 Enter로 편집기에 돌아올 수 있게 했습니다. |
| 0.1.11 | Java·JavaScript·HTML·CSS·Go·Python·Rust 언어 서버의 자동완성, 정의 이동, 진단을 연결했습니다. Ctrl+R에서 파일 실행과 로컬 웹 미리보기를 지원합니다. |
| 0.1.10 | clangd로 C/C++ 코드 완성 후보를 표시하고 선택한 이름을 삽입합니다. 함수 정의가 다른 파일에 있으면 그 파일과 줄로 이동합니다. 열린 문서의 미저장 내용을 언어 서버에 전달합니다. |
| 0.1.9 | 하단 변경사항 탭에서 작업 트리, 스테이징, 새 파일을 선택해 Git 추가·삭제 줄을 색으로 비교합니다. |
| 0.1.8 | 프로젝트별 빌드·테스트 작업을 지정하고 Ctrl+R로 기본 빌드를 실행합니다. 실행 메뉴의 터치 처리도 개선했습니다. |
| 0.1.7 | 하위 디렉터리와 열린 미저장 문서를 검색하고 결과 줄로 이동합니다. Ctrl+P로 파일명 일부를 입력해 엽니다. |
| 0.1.6 | 앱을 강제 종료해도 IDE를 다시 열면 기존 파일과 이름 없는 문서의 미저장 편집 내용을 복구합니다. |
| 0.1.5 | 하단 문제 목록과 프로젝트 터미널을 추가했습니다. C/C++ 진단을 편집기에 표시하고 목록에서 해당 위치로 이동합니다. |
| 0.1.4 | 여러 소스 파일로 구성한 C/C++ 프로젝트를 Ctrl+R로 함께 컴파일하고 링크합니다. |
| 0.1.3 | C/C++ 소스 파일을 Ctrl+R로 빌드하고 실행합니다. |
| 0.1.2 | 파일 언어에 따른 문법 강조를 추가했습니다. |
| 0.1.1 | Galaxy Terminal과 연동하는 한글 편집 입력을 개선했습니다. |
| 0.1.0 | Ubuntu ARM64에서 실행하는 터미널 IDE의 첫 버전입니다. 파일 탐색기, 여러 문서 편집, 저장, 검색 및 프로젝트 명령 실행을 제공합니다. |
